# isolated-penetration-testing-lab
Configured an isolated VMware Host-Only network connecting Kali Linux, Metasploitable 2, and Windows for cybersecurity lab practice.
Isolated Cybersecurity Lab Using VMware
Overview
This project documents the setup of an isolated virtual network using VMware Workstation for cybersecurity learning and lab practice.

Virtual Lab Environment
The lab contains three systems connected through a VMware Host-Only network.

System

IP Address

Kali Linux

192.168.2.10

Metasploitable 2

192.168.2.11

Windows Host

192.168.2.12

Network: 192.168.2.0/24
Virtualization Platform: VMware Workstation
Network Type: Host-Only

Objectives
Configure a private virtual network.
Connect Kali Linux and Metasploitable 2.
Configure network connectivity with the Windows host.
Practice basic network administration and cybersecurity lab setup.
Learning Outcomes
Understanding Host-Only networking in VMware.
Configuring IP addresses for virtual lab systems.
Preparing an isolated environment for authorized security testing.
Understanding communication between virtual machines and the host system.
Security Note
The lab is intended for educational purposes. Metasploitable 2 is intentionally vulnerable and should remain isolated from public networks.

Disclaimer
All security testing should be performed only on systems owned by the user or with explicit authorization.
